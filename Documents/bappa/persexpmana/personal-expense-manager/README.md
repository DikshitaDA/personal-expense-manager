# Personal Expense Manager

A financial tracker application that enables users to monitor income, record daily expenditures, categorize spending habits, and maintain a balanced personal budget.

## Live Demo

- Live Application: https://personalexpensemanager1.netlify.app/
- GitHub Repository: https://github.com/DikshitaDA/personal-expense-manager

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Data Persistence: LocalStorage
- Deployment: Netlify

## Key Features

- Income and Expense Tracking: Add credit and debit entries with balance recalculation.
- Categorization: Tag expenditures across food, transport, utilities, and academic needs.
- Transaction History: Chronological ledger with timestamps and quick-delete capability.
- Budget Overview: Visual summary of balance, total revenue, and total expenses.
